## Design Notes

- DRY: the payload, limits, kill on timeout or cancel, result parsing and error mapping are not duplicated per language.
- Open/closed: a language is one class plus one registry entry; nothing else branches on the language id.
- No migration: a missing `language` is Python, and Python nodes keep their bare source in `code_sources`, so the `code.write` comparison of stored graphs is unchanged.
