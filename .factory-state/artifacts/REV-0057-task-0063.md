### Non-Blocking

- **Logo sources.** The owner allowed the download in chat on 2026-10-20.
  - Slack's 2019 mark and the 2025 Teams icon are copies from Wikimedia Commons. They were not downloaded from the
    brand kits, because Slack's media kit page has no direct link. Both match the official marks and are used
    unmodified.
  - Telegram and WhatsApp are Simple Icons paths (CC0), in their recorded brand colours.
  - The one addition is a white disc behind Telegram's cut-out plane. It reproduces the official white-on-blue mark
    and does not change the mark.
- **Teams gradient ids** are prefixed with `useId` per instance (sanitised for `url(#…)`). Several Teams logos on one
  page, or one inside a hidden select, cannot pick up each other's gradients. A unit test checks this.
- **Colour exception is contained.** The tailwind-palette check and the new hex check find nothing outside
  `channel-logo.tsx`. The first version of the hex command had globs that rg did not apply (`!components/...`); it now
  uses `!**/...`, and the command was run to confirm it.
- **`vitest.config.ts` now uses the automatic JSX runtime.** This is the first `.test.tsx` that renders a component,
  and the app build already uses that runtime (plugin-react). It changes nothing for the existing `.test.ts` files.
- **Audit filter options** come from the kinds present in the log, so with an empty log there is nothing to show. The
  e2e covers it after a real Slack request.
- **Accessibility.** Every call site has the platform's name as visible text next to the logo, so the logos are
  `aria-hidden`. `standalone` exists for a future place without text.
