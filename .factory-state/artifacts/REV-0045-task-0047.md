### Non-Blocking

- `decide` now resolves the presser and delegates to `_decide`, which holds the owner/approver check, the waiting-run check, the compare-and-set, the audit, and the resume job. The link path calls the same `_decide`, so there is one copy of the rules. The 15 existing channel tests pass unchanged apart from the list of kinds.
- `_link` accepts only tokens of link kinds, so a Slack token cannot be confirmed on `/approve` without its chat identity.
- `link_info` shows the request only to the owner and listed approvers; `expired` comes from the server clock.
- WhatsApp: the signature is compared over the raw body with `hmac.compare_digest`; the GET challenge compares the verify token the same way and is rate-limited like the POST callbacks. Button titles are cut to WhatsApp's 20 characters; reply ids carry the existing tokens (well under 256 characters).
- Teams: `public_address` plus `pinned_request` as for result webhooks, redirects off. One connection per webhook (`team_id` is a hash of the URL), so the same owner can connect several Teams channels.
- E-mail: an approval fails only if every recipient is refused; the HTML is escaped.
- `channel_service._values` tolerates a kind with no secret (e-mail).
- Teams and e-mail cannot edit sent messages; DEC-0037 records it.
