## How the rules were applied
- Layering: model `WorkflowTemplate` → `TemplateRepository` → `TemplateService` (permissions, scopes) → thin `api/routes/templates.py`. Pure graph logic (built-ins, sanitiser, file format/problems) in `engine/templates.py`.
- DRY: new workflows reuse `WorkflowService.save`; view access reuses `WorkflowService.get`; permission checks reuse `AccessService`; user purge extended in `UserDataRepository.purge`.
- Envelope + English codes: 5 `TEMPLATE_*` codes (catalog, docs, en/vi). Migration on SQLite + both Postgres images.
- Strict shadcn: Dialog/Card-like tokens/Badge/Alert(warning, destructive)/Select/Textarea; preview fills are `fill-node-*` tokens. Delete via ConfirmDeleteDialog.

## Security
- Sanitiser strips resource refs and secret-like keys on every write path (save-as, import) and again on use and export.
- Personal templates are invisible to others (NOT_FOUND); org scope needs `org.manage` to create or delete.

## Worth the owner's review

- Save as template uses the last saved version and warns about unsaved changes rather than auto-saving.
