## Findings / open

- **Storage grows**: full snapshots per changing save and no retention or pruning. Fine for graph-sized JSON.
- **Restore keeps the current name**: restoring a version whose content equals the current one creates nothing, and the UI doesn't say so.
- **Restore vs. open editor**: restore replaces the editor content; unsaved edits in the open editor are lost. The confirm step is the only guard.
- **Version tagging needs an exact content match**: a run is tagged with a version only when its graph matches the latest version exactly (positions ignored). A run made from an editor opened on an older seed shape shows "unsaved" until the next save.
- **Concurrent saves**: two saves at the same instant could race on the version number. The unique constraint turns that into an error instead of a duplicate. No retry.
- **No pagination**: the version list returns everything.
