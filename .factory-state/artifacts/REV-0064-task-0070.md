### Non-Blocking

- **Fixed during review: graph values reached the code.** A retry wait, cache TTL, timeout or `top_k` was written
  as it was stored, and a canvas note was split on `\n` only, so a note with `\r` (a Python line break) or a crafted
  number could put code in the file that runs on the learner's machine. Numbers now go through `_number` (a real
  number or nothing), notes through `splitlines()`, and every text through `lit()` (a JSON string, or a triple-quoted
  one only when that keeps it exact) or `_doc()` (one line, no `"""`). `test_graph_values_never_become_code` fails on
  the earlier version and passes now.
- **Code nodes run as written.** Their code is placed inside the node function, the inner lines of multi-line
  strings left unindented so the text stays the same. The header says to read them before running the file.
- **Tool function names are reserved** before nodes are named: a node "Lookup order" becomes `lookup_order_node`,
  next to the copied `lookup_order` and its `ORDERS` constant.
- **Pass-through nodes.** Condition and Join stay nodes (`return {}`), so every canvas node has a place in the file
  and in the run's steps; the Condition's docstring says hand-written LangGraph often puts the router on the node
  before.
- **Same path, same state.** For every built-in template test case, the exported file run with `python -I` takes
  the studio's mock path and ends with the same state. Two differences show only outside the tests: LangGraph gives
  an `add` reducer field a starting `0.0`, and parallel branches can finish in either order.
- **Known limits (DEC-0045):** a reducer field written inside a subgraph is combined again when the subgraph
  returns; a Decision with a real model asks the LLM, not TypeSafe Jev; Retriever, MCP and Send email are stubs.
