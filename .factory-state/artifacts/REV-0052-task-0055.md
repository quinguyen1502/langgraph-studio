## Findings

### Non-Blocking

- **Endpoint shape differs from DEC-0041 decision 7.** Test with sample state is `POST /api/code/test` and does not sit under a workflow path. The request reads no workflow data: the caller sends the source and the state. So workflow access adds nothing, and the test also works before the first save. Recorded in the DEC-0041 addendum.
- **Failure shape.**
  - When the code itself fails, the endpoint returns a 200 result with `ok: false`, the error, the traceback and stdout, so the UI can show the traceback.
  - These stay normal API errors, shown with `errorText`:
    - bad source (`CODE_INVALID`);
    - runtime off or unavailable;
    - no permission;
    - rate limit.
- **Permission in the UI.**
  - The editor reads `code.write` from `Me.permissions`.
  - Without it:
    - the Code option is disabled for nodes that are not already Code nodes, with a hint;
    - an existing Code node shows its code read-only (`contenteditable=false`, covered by e2e), and the test button is hidden.
  - The API check from TASK-0054 still applies whatever the UI shows.
- **One source for the runtime.** `GET /api/meta/runtime` is read once per page load (`loadCodeRuntime` caches the promise and drops it on failure). The response includes the starter template, so the editor and the server use the same one.
- **Layout.**
  - Long code lines wrap (`EditorView.lineWrapping`), like the JSON editor.
  - The first screenshot showed an unwrapped line widening the config panel; this is fixed, and the light and dark screenshots now fit at 1500 px.
  - Colours are tokens only: `--syntax-key`, `--syntax-string`, `--info`, `--warning`, `--muted-foreground`, and destructive for the traceback.
- **Moved shared CodeMirror code.** The theme and fold icon moved to `lib/codemirror-theme.ts` so the component files export only components. This clears the `react(only-export-components)` warnings that oxlint raised.
- **e2e setup.** The e2e server now starts with `STUDIO_ENABLE_CODE_NODES=1`. Workflows without Code nodes are unaffected, and the Code spec skips when Docker or the image is missing.
- **Branch base.** This branch includes TASK-0054's commit, because the editor depends on `code.write`. Merge PR #62 first; PR #63's diff then shrinks to this task.
