### Non-Blocking

- **Cases fit the offline mocks.** A Condition picks the label it finds as a whole word and the Decision mock the
  label it finds in the state, so the inputs name their branch (for example the Router's "a billing question", the
  Large order's "needs a review"). Checks are on branches, decisions and filled fields, never on LLM text. The same
  inputs read naturally for a real model.
- **Knowledge base templates.** RAG Q&A and Support with escalation fail their cases until a knowledge base is
  picked (the run is invalid without one). The template test picks a small FAQ first; the handbook and templates
  page say so.
- **Case names are data**, in English like the templates' node labels; built-in template names and descriptions in
  the gallery stay translated through the locales.
- **Handbook screenshots:** only the four images this task changes were kept; the capture re-renders every image, and
  the others were restored to avoid binary churn.
