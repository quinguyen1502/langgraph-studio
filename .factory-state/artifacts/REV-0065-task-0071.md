## Findings

### Blocking

- None.

### Non-Blocking

- **Named "Code", not "Python" (owner, 2026-10-22).** Other languages (TypeScript) may follow, so the tab, the menu
  item ("View as code"), the component and the locale keys are not tied to Python; the panel shows the language as a
  badge.
- **Where the panel lives.** The task asked for a panel beside the canvas, in the same place as the run and tests
  panels: it is a tab of the bottom panel, so the canvas stays in view while a node is selected. The header entry is
  the ⋯ menu item, which comes from the same command as the palette entry (one list feeds both).
- **Saved version only.** The code is the latest saved version. Unsaved edits show a warning badge, and the code
  reloads after Save (the `saves` counter), so it never shows a graph that is not stored.
- **Highlight colour.** `--primary` at low opacity read as a grey "disabled" band in the light theme and was barely
  visible in the dark theme. The mark uses `--info` (16 %); checked in both themes and at 900 px.
- **CodeMirror only renders visible lines.** The e2e test checks the top of the file, the selected node's marked
  lines (scrolled into view) and the full text through Copy and Download.
- **Seen in the screenshots, not part of this task:** the Human node's approval channel select shows the raw key
  `approvals.notConnected` (missing in both locales) when a channel kind has no connection. Reported to the owner.
