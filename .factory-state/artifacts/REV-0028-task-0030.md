## Standards And Architecture Alignment

- Routers in `api/routes/credentials.py` call `CredentialService`. The service uses `CredentialRepository` and `engine.providers`. No FastAPI types in the service.
- New codes `PROVIDER_UNREACHABLE`, `PROVIDER_AUTH_FAILED`, `PROVIDER_BAD_RESPONSE`, `MODEL_NOT_FOUND`, `CREDENTIAL_HEADER_UNSUPPORTED`, `PROVIDER_EMBEDDINGS_UNSUPPORTED`, and `KB_EMBEDDING_DIMENSION_MISMATCH` are in `core/errors.py` `CATALOG`, `docs/api-errors.md`, `frontend/src/locales/en.json`, and `frontend/src/locales/vi.json`.
- `PROVIDER_AUTH_FAILED` stays HTTP 400, as DEC-0032 requires, so the SPA does not treat a rejected provider key as an expired session.
- Credential delete still goes through `useConfirmDelete`. The API delete stays a plain DELETE.
- `credentials-dialog.tsx` and `model-picker.tsx` add no hard-coded palette colours.

## Design Alignment

The implementation matches DEC-0032, including the three follow-ups in that decision: live tokens that are not stored, registry embeddings with per-knowledge-base `dims`, and editing a credential without returning the secret. Streaming inside subgraphs and imported runs stays out of scope, as the task says. Docker `extra_hosts: host.docker.internal:host-gateway` is on `api` and `worker`.
