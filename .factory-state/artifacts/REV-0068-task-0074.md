## Findings

### Blocking

- None.

### Non-Blocking

- **Unknown scopes do not block.** Connections saved before this task have `scopes = NULL` until they are saved or
  tested again. Blocking them would stop every existing Slack workspace from adding a trigger. The Channels page
  (TASK-0076) asks the user to test the connection. Recorded in DEC-0046.
- **Test writes the scopes.** Anyone who may use a connection may test it (read-only before). The test now also
  stores the scopes it read. That is derived metadata, not a setting, so the write is accepted.
- **A stopped trigger whose connection is gone cannot be edited.** Every save checks the connection again, so the
  user can only delete such a trigger or point it at another connection. This keeps one validation path, and the
  dialog (TASK-0076) shows the stop note.
- **A race on the unique index.** Two simultaneous creates of the same command both pass the service check, and the
  second fails on the unique index (500). This is rare (one owner editing). The index keeps the data right.
- **Fields come from the saved graph.** Unsaved state fields cannot be chosen. The dialog lists the saved fields.
