### Non-Blocking

- `TemplateEditor` is CodeMirror, as the run input already is. The stored value is the same text as before; tags are display only (`Decoration.replace` plus `atomicRanges`). The tag pattern in `lib/state-refs.ts` is the backend `VAR_RE`, so the editor tags exactly what the engine renders.
- Fields swapped: LLM prompt, Human prompt, HTTP Tool URL and body, Retriever query, MCP arguments. The URL and MCP arguments are single-line: a transaction filter turns line breaks into spaces (same length, so the selection stays valid).
- CodeMirror ignores the panel's disabled `fieldset`, so the config panel passes `readOnly={!edit}`. Viewers get `contenteditable="false"` and no insert button.
- After the insert menu closes, focus returns to the editor in `onCloseAutoFocus`. Until then a key press goes to the canvas; the spec waits for focus before Backspace. A person cannot press a key in that gap in practice.
- The wrapper copies the shadcn Input classes, including `dark:bg-input/30`. Without them the field is darker than the inputs next to it in dark mode. It uses tokens only.
- `basicSetup` turns off bracket closing, search, line numbers, and the default completion; the template completion is the only one.
- Header: the left column is now `minmax(min-content,1fr)`, so the back button and logo always fit, and the product name is in a container query that hides it below 8.5rem. The centre column is `minmax(0,auto)` and the name field can shrink to `min-w-28`. Below `lg`, Step and Run to here show their icon only; the label stays as `sr-only` text, and the tooltip is unchanged.
- `button.tsx` `sm`: the icon offset goes from `-0.5px` to `-1px`. Measured with Geist: the icon centre was 0.45px below the capital centre and is now 0.05px above it. `default` was already within 0.03px; a −1px offset there put the icon 1px high, so it is unchanged. `xs` has no labelled use and is unchanged.
