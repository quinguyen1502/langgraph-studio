## Findings / open

- **At-least-once delivery**: a recovered job re-runs from the start, so side effects of nodes that ran before the crash can repeat.
- **Recovery only at worker start**: no periodic reaper. If every worker dies, jobs wait until one starts again. That is fine for compose `restart: unless-stopped`.
- **Rate limits per process without Redis**: the in-memory limiter and queue are per process, so they are only meant for dev (documented).
- **Older tokens are unsigned**: tokens created before this change send unsigned callbacks.
- **Pending badge polls**: every 30 s and on window focus.
- **Lint**: warnings only (the existing `exhaustive-deps` pattern).
