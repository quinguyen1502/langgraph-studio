## Findings

### Blocking

- None.

### Non-Blocking

- **Every test run now runs its suite's version snapshot.** A suite stores its version, and each case runs that
  version's stored graph, including Run all on the latest version (which is the saved graph). This also pins a
  recovered test run that restarts from the beginning to its version, instead of the version that is latest at the
  restart.
- **Baseline choice.** The comparison uses the latest *finished* (`done`) suite run on a lower version number,
  whenever it ran; a cancelled suite is not a baseline. Running against an older version after a newer suite
  changes that newer suite's comparison on the next read, so the comparison you see is always against the newest
  baseline. Cases without a result in the baseline are **New**; only passed / failed results count.
- **Draft checks.** Start and End nodes are left out of the prefilled "node ran" checks (they always run); fields
  equal to the input are left out; empty values become "is empty"; values longer than 200 characters become
  "contains" their first 200 characters. The list is capped at the 30-check limit. The draft's name is
  `Run <id>` (data, not UI text); the author renames it in the dialog.
- **Who can draft from a run.** Editors of the workflow, and only for runs they could see in the run history (the
  owner and admins: every run; other editors: their own). A queued or running run is `RUN_NOT_FOUND`.
- **Stale checks** were already failed by the engine (`node_missing`, `field_missing`, TASK-0067); the panel and the
  dialog now mark them against the editor's current graph.
- **Fixed during review:** the case list showed both a change badge and a status badge, which overflowed the list;
  Regression / Fixed now replace the status badge (they say failed / passed). The Test history menu was too narrow.
- **Fixed after the owner's review:** the pass / fail icons in the check table sat below the text line (inline SVG on
  the baseline, and the stale badge made its row taller); the icon is now centred on the first line and the badge is
  shorter.
