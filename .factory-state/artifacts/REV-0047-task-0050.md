### Non-Blocking

- Keys stay inside the provider layer. `request()` maps HTTP status to catalog codes, and `test_run_with_a_typesafe_credential` asserts the key is not in any event.
- `ask()` checks the credential's provider class, so a chat credential on a Decision node fails with a readable message before any call.
- The answer for each question is required. A response missing one is `PROVIDER_BAD_RESPONSE`, not a silent `None` in state.
- The parallel-writes check now uses `written()`. Decision nodes declare every field they write, and For each nodes declare their item and index fields, which were not counted before.
- Removing a question, option, or level is a canvas edit, undoable with Ctrl+Z like deleting a node, so it is outside ui-conventions rule 7 (stored items). The hint says so.
- Fixed during the visual check: the config panel overflowed with the long no-credential label (Radix ScrollArea content grows to its widest child).
