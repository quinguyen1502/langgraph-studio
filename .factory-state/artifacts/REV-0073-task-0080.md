## Review Scope

- `TypeScript` strategy in `engine/code_languages.py`, which covers:
  - the static check: `export ... main`, plus the import allowlist with comments stripped and strings kept;
  - the `deno run` flags: no `--allow-*`, plus `--no-prompt --no-remote --cached-only --no-config --no-lock` and the V8 heap cap;

  - per-language rlimits and out-of-memory exit codes.

  - `STUDIO_CODE_TS_DENO_DIR`.

## Findings

### Blocking

### Non-blocking

- A computed `import(x)` is not caught by the static allowlist. `--cached-only` plus no network still stops anything uncached from loading (DEC-0049).
- The Docker runtime is untested locally (no Docker on the box). The new CI job covers it.
- On the host runtime, packages need `STUDIO_CODE_TS_DENO_DIR` (a Deno cache filled with `deno cache`). Without it the allowlist is empty, so the editor does not promise packages that cannot load.
